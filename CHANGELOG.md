# Changelog

Versions stay `v0.x` until the API settles: the minor version marks changes
that may break callers, the patch version marks fixes.

## v0.3.0

- Requires `ferron >=0.8.0-alpha.1`; CI pins `FERRON_REF: v0.8.0-alpha.1`.
  The package slices with ranges (`text[1..]`), since Ferron 0.8 removed
  the `slice` methods (D77). The API is unchanged: callers move to
  Ferron 0.8 and change nothing else.

## v0.2.0

- Requires `ferron >=0.7.0-alpha.1`; CI pins `FERRON_REF: v0.7.0-alpha.1`
  and builds `anvil` with the compiler's `scripts/build-anvil`.
- Builds under D70, where counts and indexes are `Int`: `Database.execute`
  and `Transaction.execute` return `Result[Int, SqliteError]` (was
  `usize`). **Migration:** drop `usize` conversions and suffixes on the
  count.
- Builds under D68 value semantics: locals the package changes in place
  are declared with `var` (applied with `anvil fix`).
- Test types use natural names (`User`, `Person`) again: the compiler no
  longer shares a generic instance between same-named types of different
  packages.
- `include/sqlite3_handles.h` and the generated `src/sys/sqlite3_handles.fer`
  are gone: `anvil ffi gen` now makes opaque types `pub` on its own. The
  `sqlite3_ptr` and `sqlite3_stmt_ptr` aliases went with them (they were
  package-internal).

## v0.1.0

- First release: SQLite 3 through FFI over the system `libsqlite3`
  (3.37 or newer), replacing `std.sqlite`, which left the standard library.
- `sqlite.database`: `Database.open(fs, path)` and `Database.memory()` as a
  resource closed with `sqlite3_close_v2`; `execute` and `query` with `?`,
  `?N`, `:name`, `@name`, and `$name` parameters bound through
  `sqlite3_bind_*`; rows decoded through `FromData`; `Transaction` as a
  resource that commits on `commit` and rolls back otherwise; statements
  prepared as resources finalized with `sqlite3_finalize`.
- `sqlite.error`: `SqliteError` with a kind from the result code, the
  extended code, and `sqlite3_errmsg`.
- Bindings: `src/sys/` generated by `anvil ffi gen` from `sqlite3.h`,
  pinned to the functions the package calls so the output is the same for
  every 3.x header from 3.37 on; `sqlite3_bind_text` hand-written with
  `SQLITE_TRANSIENT`.
- Requires `ferron >=0.6.0-alpha.1`; CI pins `FERRON_REF: v0.6.0-alpha.1`
  and checks `live_handles=0` after `anvil test`.
